🎯 Problem Statement & Objectives

Problem Statement

Chess has ~10120 possible game states — enforcing all legal rules and building a functional AI is a significant software engineering and algorithmic challenge.

Goal: build a rule-complete, interactive chess application in Java with multiple difficulty levels of AI opponent.

Objectives

  • Implement a fully playable chess game using Java Swing GUI
  • Enforce all standard chess rules (movement, check, checkmate, stalemate, castling, pawn promotion)
  • Build AI bots using the Minimax algorithm with Alpha-Beta Pruning
  • Support two game modes: Human vs. Human and Human vs. Bot
  • Provide four difficulty settings: Beginner, Amateur, Intermediate, Hard

🔷 OOP Concepts Applied

🔒 Encapsulation

  • Piece stores isWhite and isMoved as private fields; exposed only through getters
  • Board encapsulates the 8×8 grid; external access only via getSquare(row, col)

🔗 Inheritance

  • All six piece types extend the abstract class Piece
  • Shared behaviour is inherited; movement rules are overridden

🔄 Polymorphism

  • Piece.isValidMove() is declared abstract — each subclass provides its own implementation
  • ChessBot interface: getBestMove() called uniformly

🧩 Abstraction

  • Piece (abstract class) hides movement implementation details
  • ChessBot (interface) hides the entire AI algorithm

📸 Memento Pattern

  • Implemented via GameState inner class to snapshot board state, active pieces, and turn info
  • Used for robust Undo functionality by restoring deep-copied Piece arrays

Alpha-Beta Pruning: Prunes branches when β ≤ α, reducing branching factor from O(bd) to O(bd/2).

Move Ordering (MVV-LVA)

  • Promotions → +8000
  • Captures → 10 × victim_value − attacker_value
  • Quiet moves → 0
  • Intermediate/Hard: adds PST delta for positional ordering

Piece-Square Tables

Technical Challenges & Solutions

🐛 The Ghost Pawn Bug

Tracking ephemeral target squares during recursive Minimax search triggered pawns capturing their own color's "ghosts", causing activePieceCoords array to silently corrupt and overflow.

✔ Fix: Strict color validation for En Passant + safe boardToIndex default of −1.

🧊 UI Thread Freezing

Checkmate/surrender popups blocked the Swing Event Dispatch Thread.

✔ Fix: Wrapped all end-game dialogs in SwingUtilities.invokeLater().

🖥️ UI Flickering During Bot Turn

Bot's Minimax mutates the board object shared with the UI.

✔ Fix: Isolated simulation via Board snapshot; UI freezes while botThinking = true.
